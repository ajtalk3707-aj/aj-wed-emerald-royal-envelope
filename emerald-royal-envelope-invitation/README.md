# Emerald Royal Envelope & Book Wedding Invitation - AJ Invitation (રોયલ એન્વેલપ કંકોતરી)

A standalone luxury animated Gujarati wedding invitation built with React + Vite + Tailwind CSS featuring an interactive 3D Royal Wax Seal Envelope intro and a 3D Book page-flipping experience.

## Features
- 💌 **Interactive Royal Wax Seal Envelope**:
  - Pulsing golden wax seal with royal ruby envelope
  - 3D envelope unsealing and flap flip animation (`rotateX(180deg)`)
  - Smooth extraction of royal parchment letter into the 3D book stage
  - Ability to re-close envelope anytime from the top bar
- 📖 **3D Book Page-Turning & Scroll Animation**:
  - Realistic 3D book spine folding effect (`rotateY(-105deg)`)
  - Mouse wheel / trackpad scroll turns book pages forward and backward smoothly
  - Touch swipe support for mobile and touchscreen devices
  - Keyboard navigation (Arrow keys, Space, Page Up/Down, Home, End, Escape to close envelope)
- 🌿 **Royal Emerald & Gold Botanical Aesthetics**:
  - Intricate botanical vine borders with gold and emerald leaves
  - Shimmering gold foil animated typography
  - Cascading emerald, gold, and ruby petals
- 📜 **8 Complete Gujarati Ceremony Pages**:
  1. કવર (Ganesh Shloka, Couple Photos, Wedding Date, Inviters)
  2. વિવાહ સંસ્કાર (Wedding Announcement, Mangalya Shloka)
  3. હલ્દી રસમ (Haldi Ceremony & Lunch Timing)
  4. લગ્નોત્સવ (Mandap Muhurat & Feast)
  5. પ્રેમ રાસ (Royal Midnight Emerald Theme, Raas-Garba & Sangeet Sandhya)
  6. જાન પ્રસ્થાન & હસ્ત મેળાપ (Wedding Day & Hast Melap)
  7. લિ. સ્નેહાધીન & દર્શનાભિલાષી (Family Members)
  8. મોસાળ પક્ષ, ફર્મ & શુભ સ્થળ (Interactive 1-Click Google Maps & WhatsApp RSVP)
- 📷 **Couple Photo Upload**: Instant client-side upload for Groom & Bride with auto-scaling and `localStorage` persistence.
- 🎵 **Auspicious Shehnai Melody**: Built-in Web Audio synthesizer playing traditional wedding Shehnai melody.
- 📍 **One-Click Actions**: Instant Google Maps navigation to Nilkanth Farm Party Plot and WhatsApp RSVP button with pre-filled Gujarati greeting message.
- 📱 **100% Mobile & Desktop Responsive**: Auto-adapts dimensions for phones, tablets, and wide monitors.

## How to Run

1. Open terminal in this folder:
```bash
npm install
npm run dev
```

2. Open the local link in your browser:
```
http://localhost:5178
```

3. To build for production:
```bash
npm run build
```
The production bundle will be created in the `dist` folder.
