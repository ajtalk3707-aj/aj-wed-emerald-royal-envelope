# Swarna Elegance – Animated Royal Edition | AJ Invitation (સ્વર્ણ એલિગન્સ કંકોતરી)

A standalone luxury animated Gujarati wedding invitation built with React + Vite + Tailwind CSS + Framer Motion. Features 7 distinct animated atmospheric palettes, Shehnai & Tanpura melody synthesizer, flower shower particle effects, auto-play presentation mode, and smooth scroll animations.

## Features
- 👑 **Swarna Elegance 7-Celebration Color Palettes**:
  1. **શુભ વિવાહ & યુગલ પરિચય**: Sunlit Golden Amber Brocade & Crimson velvet
  2. **વિવાહ સંસ્કાર (માંગલ્યમ્)**: Sacred Saffron Kesari & Sunset Marigold
  3. **દિવસ ૧ : રસમ & ગરબા**: Luminous Bright Turmeric Haldi yellow
  4. **દિવસ ૨ : શુભ વિવાહ**: Ruby Sindoor & Rose Velvet
  5. **શુભ સ્થળ દર્શન**: Royal Palace Garden Emerald Mint & Nilkanth Farm
  6. **કુટુંબ સ્નેહ**: Royal Sapphire Navy & Sky Blue Silk
  7. **મધુર કલરવ**: Romantic Royal Orchid Lavender & Magenta
- 🌸 **Interactive Flower Shower (પુષ્પવૃષ્ટિ)**: Real-time falling ceremonial floral petal animation.
- 🎵 **Shehnai & Tanpura Web Audio Synthesizer**: Realistic Tanpura drone + Shehnai Yaman Raag melody with organic reed vibrato.
- ▶ **Auto-Play Presentation Mode**: Smooth leisurely slideshow for automatic viewing.
- 📜 **Scroll-Based & Gesture Navigation**:
  - Mouse wheel and trackpad scroll to flip cards forward and backward
  - Touchscreen swipe left/right for smartphones and tablets
  - Keyboard navigation (Arrow keys, Space, Page Up/Down, Home, End)
- 📷 **Couple Photo Upload**: Instant client-side upload with canvas compression and `localStorage` persistence.
- 📍 **One-Click Actions**:
  - Google Maps direct navigation to Nilkanth Farm Party Plot
  - Calendar (.ics) event download
  - WhatsApp RSVP greeting message with one tap
- 🪔 **Royal Ornate Details**: Rajputana Jharokha arch, rotating mandala watermark, and hanging festive torans.

## How to Run

1. Open terminal in this folder:
```bash
npm install
npm run dev
```

2. Open the local link in your browser:
```
http://localhost:5179
```

3. To build for production:
```bash
npm run build
```
The production bundle will be created in the `dist` folder.
